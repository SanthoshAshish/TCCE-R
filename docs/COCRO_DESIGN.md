Status: **design only; nothing is implemented.** Branch `cocro-dev` (worktree `../tcce_r_cocro`, from `revision-v0.8` at 6cb5a4e). No code, config, result or manuscript file has been changed.
Labels: **[E]** established result or standard technique; **[P]** proposed, unvalidated; **[A]** assumption. Nothing marked [P] is a claim of novelty or performance.

## 2. Algorithm: COCRO (v2)

### 2.1 Idea [P]
At each epoch: (CFPE) update a posterior failure model; draw independent scenario sets from it; for each candidate action compute its **expected marginal future resilience gain to the end of the run** (CMVE), including the setup outage; compute the **shadow price Λ of one unit of the remaining mutation budget by policy rollout** (MOCO); **rewire iff the best net gain ≥ Λ**, else defer/reserve. Uncertainty enters through posterior sampling (UABR) and cross-fitted scenario sets.

### 2.2 State and estimators (centralised controller [A1])
- Topology Q_k, live/down masks, ready_at, remaining budget m_k = M − used, remaining epochs τ_k = T − k, tabu times; link-state history; adjacency (line-graph; optionally spatial radius) [A2].
- **CFPE posterior θ** (all with exponential forgetting φ per epoch [A3, regime switching]):
  - baseline link failure hazard h with hierarchical Beta prior (partial pooling; pooled value used for links without history, including candidate additions);
  - lagged-adjacency lift: failure hazard of a link whose N_e adjacent links were down in the previous epoch is h·λ^{N_e}; λ from posterior odds [E: conjugacy]; an interpretation as contagion is **not** claimed (R7);
  - downtime as a two-component geometric mixture (short r_s, long r_l, weight w) fitted by a censored-data likelihood (ongoing episodes are right-censored) with a Dirichlet prior;
  - node-level latent failures: a node is flagged down when all its incident configured links fail in the same epoch; node hazard and repair estimated separately; incident-link failures are then not attributed to propagation.
- **TRDE**: persistence probability π_e(a) = P(remaining downtime > d+H | age a, θ) = [w_l(1−r_l)^{a+d+H} + w_s(1−r_s)^{a+d+H}] / [w_l(1−r_l)^a + w_s(1−r_s)^a]; criticality c_e = first-order λ2 share (Σ c_e = 1 [E]); damage ledger
  D_{k+1} = (1 − Rec_k)·D_k + Σ_{e open} c_e·π_e·(1 + λ̂ N_e) + E_θ[Σ_{e live} 1{e fails within H}·c_e],
  Rec_k = (damage mass Σ c_e π_e repaired or removed this epoch) / (damage mass at the previous epoch), 0 if none: parameter-free, structural. D is a state estimator, an optional compute screen and a diagnostic; **it is not compared with a threshold**.
- Calibration map ĝ: isotonic regression from predicted Ê to realised E over past epochs (online, with the previous epochs only).

### 2.3 Objective [P]
Surrogate error of a graph Q (Metropolis weights, T rounds, tolerance ε): Ê(Q) = 1 − min(1, −½ ln( Σ_{i≥2} λ_i(W)^{2T} / (n−1) ) / ln(1/ε)) [E: expected squared contraction for i.i.d. centred x(0)]; transient per-round failures enter through survival weights q = 1 − p_transient in W (approximation, Jensen gap acknowledged); Ê is then passed through the learned map ĝ. Disconnected Q ⇒ Ê = 1 (component logic is exact).
For a scenario ω ~ p(·|θ, history) (failure paths for epochs k+1…k+H, extrapolated beyond [A8]):
  per-epoch gain at epoch t: δ_t(a,ω) = Ê(Q_t^null(ω)) − Ê(Q_t^a(ω)), with Q^a including the setup outage (old link removed from k+1, new link usable from k+1+d);
  S_setup(a) = E_ω Σ_{t=k+1}^{k+d} δ_t(a,ω)  (typically ≤ 0 when a live link is released),
  b(a) = E_ω mean_{t=k+d+1}^{k+d+H} δ_t(a,ω)  (benefit rate once ready; the added link's own failure hazard is inside ω),
  **G(a) = S_setup(a) + b(a)·(τ_k − d)**, truncated at 0 remaining epochs; null action G = 0.
  Decomposition reported, not weighted: G_imm = S_setup + b·(H0 − d) with H0 = d+1; G_fut = the rest; plus a separate column for cascade-prevention (gain in scenarios flagged as cascading).
  Net gain: N(a) = G(a) − c_op·1{a ≠ null}; c_op in error-epochs (primary analysis c_op = 0; sensitivity otherwise).
Assumption A8: the benefit rate b stays stationary until the end of the run (only the sampled window H is simulated). Tested by comparing predicted G with realised gains from the delayed replay.

### 2.4 Shadow price by rollout (MOCO) [P]
Base policy π₀: "greedy slot policy": at coarse slots spaced c_s epochs (default c_s = 4), execute the best-gain candidate (by the cheap surrogate) whenever its net gain is positive and cooldown/budget allow. Within each posterior scenario (cross-fitted set S_test), simulate π₀ to the end of the run twice from the *current* state with common random numbers, with the extra unit of budget available (m units) and withheld (m−1 units), and compute the realised total gain difference. The shadow price of one unit **if the mutation is deferred** is
  Λ_roll = E_ω[ W_{π₀}(wait; m) ] − E_ω[ W_{π₀}(act-then-continue; m−1) − G_now(a*, ω) ],
i.e. the expected extra total gain obtainable by keeping the unit and waiting, over the gain realised by acting now. Rule: **act iff N(a*) ≥ Λ_roll** (equivalently, one-step policy improvement over π₀ [E: Bertsekas rollout / policy improvement; improvement over π₀ holds for the model value, up to Monte-Carlo error]). Because rollouts are run inside correlated scenarios with the true cooldown, serial correlation, diminishing returns and persistent-flow rewards are handled by construction. A fast **i.i.d. DP surrogate** W(τ,m) = E_F[max(g + W(τ−1,m−1), W(τ−1,m))] is retained only as an ablation and a speed comparison; it is expected to over-defer (R2).
Under stationary damage the persistent-flow reward grows with remaining time, so COCRO is expected to **reduce to early action** (like A7) unless future events are expected to be larger or the posterior says current damage is probably temporary; gains over A7 are therefore only hypothesised where damage is non-stationary, heavy-tailed or late (H1, H2).

### 2.5 Counterfactual mutation-value estimation and delayed credit (CMVE) [P]
- Before acting: G is a counterfactual over sampled **alternative future topology states**.
- After acting: at k+d+H (short) and k+d+H_long (H_long = 20) compute the realised with/without replay (existing past-only machinery [E]); **lasting credit** = realised mean gain in (k+d+H, k+d+H_long]; transient part = gain in the earlier window that disappears. Ordered marginal attribution (baseline includes earlier mutations only). Mutations whose long window ends after the run are **censored** (reported, not credited): late mutations are never calibrated.
- Credit updates (i) a shrinkage factor κ̂ (posterior toward 1) multiplying future b and (ii) the base-policy parameters of π₀ only through b-calibration. κ̂ is fitted only on acted-upon actions, which embeds selection bias that partly offsets the winner's curse; reported as a diagnostic, not assumed unbiased. No effect on budget accounting or past decisions; double counting is prevented as in `docs/R2_DESIGN_RULES.md` §4.

### 2.6 Uncertainty and cross-fitting (UABR) [P]
Every scenario draws θ from the posterior (Thompson-style), integrating parameter uncertainty; each currently-down link draws its downtime component from the posterior given its age. Two **independent** scenario sets S_sel and S_test: S_sel selects a*; S_test estimates N(a*) and the rollouts. Diagnostics: posterior sd of G, P(N>Λ). Variants (separate arms): plug-in (MAP) θ; lower-confidence-bound rule.

### 2.7 Constraints
Σ_k m_k ≤ M (counter checked before the gate); ≤1 mutation/epoch; cooldown 2 after a success; strict configured-edge budget; every action through the unchanged `SafetyGate`; rewires only (as all arms; add-only occurs only if the budget is not full and is covered by the same candidate generator). Decisions use data up to epoch k only; **controller scenario RNG streams are independent of the environment's streams** (seeded from (seed, epoch, role), never from the pre-generated trace); tested.

### 2.8 Pseudocode
```
at the end of epoch k (after observing link states):
    update CFPE (forgetting φ), TRDE (π_e, N_e, D_k, Rec_k), calibration map ĝ
    if m_k == 0 or cooling down: return null
    if screen_on and D_k small and predicted new-damage mass small: return null        # compute screen (ablation)
    draw S_sel and S_test independent scenario sets (θ_s ~ posterior; downtime components ~ posterior given age)
    candidates A_k = top-K_r removals (failed links valued by π_e) x top-K_a additions, filtered by SafetyGate
    for a in A_k: G_sel(a) ← S_setup + κ̂·b·(τ_k − d) on S_sel;   a* ← argmax_a G_sel(a) − c_op
    N* ← G_test(a*) − c_op on S_test
    Λ ← rollout shadow price on S_test (base policy π₀, slots every c_s epochs, common random numbers)
    if N* ≥ Λ: return a*   else: return null     (label: defer if a* beats null, reserve otherwise)
after each mutation: register for delayed credit; when windows close, update κ̂ and diagnostics
```

### 2.9 Complexity (re-derived; estimates are to be measured, not claimed)
Notation: n nodes, P potential links, S scenarios, H window, K = K_r·K_a candidates, B = number of rollout slots (≈ τ/c_s), c_eig(n) = cost of a dense symmetric eigendecomposition (measured on this machine: 0.17 ms at n=40, 0.67 ms at 80, 3.8 ms at 200, 62 ms at 500).
- posterior update O(P); scenario sampling O(S·H·P) (+ adjacency O(S·H·P·deg)).
- **Exact spectral gain**: one eigendecomposition per (scenario, epoch, candidate and null): O(S·H·(K+1)·c_eig(n)). Example n=40, S=16, H=5, K=24: ≈ 2,000 evaluations ≈ 0.35 s per decision epoch; n=200: ≈ 8 s per decision epoch — too slow for 150 seeds × many cells without the screen.
- **Laplacian first-order surrogate** (large n): one eigendecomposition per sampled graph and rank-one updates per candidate: O(S·H·(c_eig(n) + K·n)); valid only on connected sampled graphs (components handled by union–find, O(P α)); Metropolis spectrum is *not* rank-one updatable (R3), so Ê is replaced by the λ2 surrogate and validated by rank correlation on development seeds. Sparse Lanczos replaces c_eig(n) beyond n ≈ 500.
- **Rollout**: two rollouts × S scenarios × B slots × (candidate ranking by first-order gain: one eigendecomposition per slot plus one after each simulated mutation) ≈ O(2·S·B·c_eig(n)); n=40: ≈ 0.1 s; n=200: ≈ 5 s per decision epoch (estimates).
- With the screen skipping ~80% of epochs the n=200 cost is ≈ 1–2 min/run (estimate); n ≥ 500 only with the surrogate, small S, few seeds. Memory O(S·H·P) booleans. Decision time and memory will be measured with CIs.

### 2.10 Assumptions and parameters
Assumptions: A1 centralised exact-model controller (as B8); A2 link states observed (noise/delay tested separately), adjacency/positions known; A3 failure process = Markov with lagged-adjacency lift and downtime mixture, slowly drifting (forgetting), possibly misspecified (tested under cascading, node and regime-switching failures); A4 consensus model known; A5 (removed as a basis for decisions; i.i.d. gains only in the surrogate ablation); A6 interaction among mutations handled by rollouts; A7 weakly informative fixed priors; **A8** stationary benefit rate after the simulated window; A9 the calibration map is stationary over a run.
Parameters (all fixed in advance, none tuned on held-out data; sensitivity analysis on development seeds): S_sel=S_test=16, H=5, K_r=3, K_a=8, slot spacing c_s=4, forgetting φ=0.98, c_op=0 (primary), prior strengths = B8's hazard priors, H_long=20, screen on only in scalability tiers. This is **not** a parameter-free algorithm: it has no multi-objective weights α…δ and no debt threshold or adaptive Θ, but it has the listed constants.

## 3. How COCRO differs, and the novelty test
| Aspect | B8 | C1 | **COCRO** |
|---|---|---|---|
| Trigger | threshold on CUSUM debt | threshold on ledger debt | **no threshold**: act iff net gain ≥ shadow price of a mutation unit |
| Value of a mutation | weighted sum J, one-step expected-matrix proxy | same | **expected future error reduction to the end of the run**, setup outage included, spectral surrogate |
| Where | fixed removal, choose addition | same | joint removal × addition search |
| Future / uncertainty | global hazards, deterministic | same | link-specific, propagation- and node-aware, posterior sampled, cross-fitted |
| Budget | cap only | cap only | opportunity cost via rollout: defer/reserve explicit |
| Counterfactual | past replay → Θ | same | forward alternative futures; delayed lasting credit → calibration |
| Persistence | none | hard cut d+2 | censored-likelihood mixture π_e |
**Novelty test (honest).** Against the existing code the decision mechanism differs in kind. Against the literature the ingredients are standard (posterior sampling, optimal stopping/rollout, Lagrangian/Whittle-type shadow prices, model-predictive topology control); **no novelty claim** until the systematic literature comparison (Phase 6). The scientific contribution claimed is a controlled test of whether opportunity-cost reasoning helps. If COCRO with Λ ≡ 0, plug-in θ and fixed removal is not distinguishable from full COCRO, the added mechanism is not established and the paper says so.

## 4. Fairness design
- Identical failure traces and gate/budget for all arms (existing CRN, extended to new failure models); scenario RNG of the controller is separate (leakage test).
- Count matching: **A7C** (A7 with exactly COCRO's realised count on the same seed, two-stage), **A6C** (random-timing schedule with the same count), **COCRO-M** (COCRO with Λ ≡ 0 until the budget is spent), count-matched subsets, budget-sweep curves M = 1…8 with Pareto analysis against overhead.
- **Oracle headroom analysis**: per seed, the best fixed-offset A7-type schedule chosen with hindsight of the trace; if the oracle is not better than A7, no adaptive policy can be expected to beat A7 and the paper must say so.
- Disclosed asymmetries: COCRO uses adjacency, hazards and spectral evaluation that A1/A7 do not; compute is orders of magnitude larger (decision time reported with CIs; no compute-matched comparison is made).
- B8/C1/A1 calibrated by the amended capped-count rule on calibration seeds; COCRO has no threshold. Development seeds may guide design until the **design lock** (committed protocol); the held-out run is used once.
- Pre-registered **primary comparisons** (main tier): COCRO vs A7C, vs B8, vs A7M; everything else secondary/exploratory and labelled.

## 5. Theoretical results planned (assumption-dependent; proofs to be written and numerically checked)
P1 Budget feasibility: Σ m_k ≤ M and the edge budget are never violated (induction over counter and gate). **[E-level]**
P2 No controller-induced disconnection: accepted actions never increase live components (live and interim) and keep λ2 ≥ min(λ2_min, λ2_before) — a gate property; failures can still disconnect.
P3 Consensus error: for epochs whose round graphs are connected, the expected squared error contracts at the stated spectral rate [E]; for time-varying topologies only a **conditional bounded-error** statement under joint connectivity; no unconditional convergence claim.
P4 Debt: with bounded damage arrival and Rec_k = 1 on recovered intervals, D_k ≤ D_max (geometric bound); persistent unrecovered damage makes D grow linearly by design (stated).
P5 (revised) **Policy improvement**: the rollout rule is at least as good as the base policy π₀ in the *model* value, up to Monte-Carlo error [E: rollout theorem]; for the i.i.d. one-shot surrogate the threshold policy is optimal with Λ nonincreasing in m and nondecreasing in τ [E], **not claimed** for the persistent-flow model (checked numerically). Λ ≡ 0 gives the greedy rule.
P6 Estimator: G is unbiased for the model-expected gain with cross-fitting removing the selection bias; standard error O(S^{-1/2}); CRN reduces paired variance.
P7 Complexity as §2.9.

## 6. Evaluation plan
**Seeds** (disjoint from all earlier ranges): development 8500–8539, calibration 8600–8639, held-out 9300–9449 (150/condition; with paired SD ≈ 0.05 the minimum detectable effect is ≈ 0.011 at 80% power; larger SD ⇒ more seeds). Large-n tiers use fewer seeds with CIs.
**Graphs:** random geometric 40, 80, 200, 500; Erdős–Rényi 100, 200, 500; Barabási–Albert 100, 200, 500; Watts–Strogatz 100, 200, 500 (new); heterogeneous scale-free 200, 500, 1000 (new). Largest sizes limited by compute; limits reported.
**Failure models (additive, default off):** background Markov; spatial bursts; repeated/clustered bursts; cascading (neighbour hazard lift for a few epochs); node failures; link+node; regime switching (unseen bursts); mobility/rapid change; trace-driven only if a public trace is obtained and licensed (otherwise a stated limitation, never simulated as "real").
**Tiers:** A main (RGG 40/80 × 3 scenarios × M ∈ {3,6}); B topology sweep; C failure sweep; D scalability (timing, memory, evaluations per decision, CIs); E observation noise/delay.
**Arms:** A0, A1, A7, A7M, A7C, A6C, B8, C1 (unchanged baselines) vs COCRO, COCRO-M.
**Ablations (component and interaction):** COCRO minus each of: lagged-adjacency lift (λ≡1), persistence mixture (hard cut), structural recovery decay, node latent state, uncertainty (plug-in), opportunity cost (Λ≡0), rollout price (i.i.d.-DP price), delayed credit (κ̂≡1), joint removal search, forward scenarios (S=1/expected matrix), cross-fitting (single scenario set: quantifies the winner's curse), screen, spectral vs Laplacian surrogate; interactions: (opportunity cost × uncertainty), (propagation × persistence), (credit × opportunity cost), (rollout × cross-fitting). Matched counts and identical traces throughout.
**Valuation/predictor validation:** forecast calibration (Brier, log-loss, reliability/ECE); predicted-vs-realised gain error with CIs; horizon (H, H_long) sensitivity; decomposition of closed-loop gains into selection, deferral and count effects on fresh seeds (the open E1-vs-closed-loop discrepancy).
**Sensitivity (development seeds only):** one-at-a-time and small Latin hypercube over c_op, S, H, K_r, K_a, c_s, φ, prior strength, failure intensity, setup delay.
**Metrics:** mean and worst-case E; convergence time with censoring handled (restricted mean survival time/Kaplan–Meier on a longer window, separate from the T=60 epoch metric); P(connected); λ2; recovery time; mutation efficiency; overhead; Brier/ECE; failure-detection precision/recall; energy proxy (messages = live links × rounds + reconfiguration units; a proxy); decision time and memory with CIs.
**Statistics:** paired Wilcoxon, effect sizes, bootstrap CIs (10,000), margin 0.02 (0.01 in the 150-seed main tier, declared in advance), Holm within each family, Benjamini–Hochberg across tiers; primary vs exploratory labelled.

## 8. Established vs proposed — summary
Established [E]: Fiedler first-order gain; Metropolis consensus and expected squared contraction; Beta/Dirichlet conjugacy, censored likelihoods, EM; Bellman recursion and the policy-improvement/rollout theorem; Thompson-style posterior sampling; Monte-Carlo error; CRN; Holm/Wilcoxon/bootstrap/BH. Proposed [P]: the lagged-adjacency persistence model combined with the structural-recovery ledger (TRDE), the to-the-end-of-run marginal-gain objective with setup outage and spectral surrogate (CMVE), the rollout shadow-price decision (MOCO), the lasting-credit calibration, cross-fitted selection, and the COCRO integration. Hypotheses (tested, negative results reported): H1 with matched counts COCRO ≤ A7C in E where damage is late, persistent or non-stationary and ≈ where it is early/static; H2 reservation helps under late or heavy-tailed shocks, not under early-dominant failures; H3 posterior sampling beats plug-in under non-stationary hazards; H4 delayed credit lowers gain-prediction error; H5 propagation-aware hazards improve forecast Brier score under cascading failures; H6 the rollout price defers less often and performs better than the i.i.d.-DP price under correlated damage.

## 9. Implementation status (C0b and C1; updated after implementation)
Implemented on branch `cocro-dev` (all new files, no existing file modified): toy study (`tccer/toy/shadow_price.py`, `experiments/toy_shadow_price.py`, `docs/COCRO_TOY_STUDY.md`; all five pre-declared criteria pass, with the limits stated there), CFPE (`tccer/core/failure_model.py`), scenario sampler (`tccer/core/scenarios.py`), gain estimator (`tccer/core/value.py`). **Not implemented:** the shadow-price/rollout component in the simulator (gated on the toy study, which passed; awaiting review), TRDE, CMVE credit, the COCRO policy, new environment failure models, new graph generators, experiments.
Deviations from the text above, found during implementation:
* CFPE uses a **bucketed** lagged-adjacency hazard h[N], N = 0, 1, 2, 3+ (empirical-Bayes pooling toward bucket 0), a nonparametric superset of h*lambda^N; reported lift is h[1]/h[0], an association, not a causal estimate. Per-link heterogeneous hazards, spatial common-cause shocks and change-point detection are not implemented (pooled per bucket; forgetting only).
* The downtime-mixture posterior is sampled by a **Bayesian bootstrap + censored EM refit** per scenario (not a closed-form posterior).
* **Measured surrogate bias (R4 confirmed):** the spectral error surrogate is above the simulated mean metric by 0.04-0.09 at mid-range (n = 24-40 ring-plus-chord graphs, T = 60), ordering preserved; the isotonic calibration map reduces the held-out error in the unit test. **Floor effect (R4 confirmed):** graphs with n <= 14 converge below eps within an epoch (E = 0), so two such graphs have zero measured gain; the experiments must use sizes/horizons where E is not saturated, and the metric's floor limits what any controller can show on small, well-connected graphs.
* The Laplacian surrogate (E_L from a lambda2 contraction bound) is implemented; its agreement with the spectral value is only tested on random ring-plus-chord graphs (Spearman > 0.8); the check on development-seed states is still to be done.
